Scripts de ayuda local para PhoenixTask®.

- `dev-up.sh` — arranque completo (DB + backend + frontend)
- `dev-down.sh` — parada limpia y liberación de puertos
- `dev-reset.sh` — reset + reseed demo
- `dev-smoke.sh` — validación rápida del entorno
- `build-backend.sh` — build reproducible del backend (sin tests)
- `build-frontend.sh` — build reproducible del frontend
- `ci-check.sh` — build backend + frontend (base CI)

Documentación operativa: `docs/runbook-ops.md`
