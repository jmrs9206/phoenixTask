# UX_DATA_CAPTURE_POLICY

## Principio
Máxima selección, mínimo input libre.

## Reglas
- Todo dato operativo debe estar estandarizado.
- Usar catálogos, selects, radios, toggles, autocompletes y referencias controladas.
- Texto libre solo para contenido humano real.

## Catálogo cerrado
Usar select o radio para:
- estado
- prioridad
- tipo de issue
- categoría
- rol
- tipo de notificación
- tipo de KPI
- columnas
- estado de sprint

## Catálogo semiabierto
Usar autocomplete / creación controlada para:
- etiquetas
- componentes
- plantillas
- motivos configurables

## Texto libre permitido
- título
- descripción
- comentario
- mensaje
- observaciones
- notas internas
