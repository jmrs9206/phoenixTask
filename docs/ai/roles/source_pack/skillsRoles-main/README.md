# SkillsRoles: The Elite Tech Squad AI Prompts

**skillsRoles** es un framework de *System Prompts* de élite diseñado para configurar Modelos de Lenguaje Grande (LLMs como GPT-4, Claude 3.5 o Gemini) con mentalidades de ingeniería hiper-especializadas. 

Cada prompt está construido bajo la premisa de la **separación estricta de responsabilidades**: cada rol tiene un área de dominio ultra-profunda, restricciones inquebrantables ("qué NO hacer") y un formato de salida quirúrgico.

---

## 💡 Cómo usar este repositorio

1. Navega por el índice de roles a continuación o explora directamente las carpetas del repositorio.
2. Abre el archivo `.md` del rol que necesites.
3. Copia el bloque de texto completo.
4. Pégalo como **System Prompt** o **System Instruction** en la configuración de tu IA (o como primer mensaje en tu chat).
5. Interactúa solicitando tu requerimiento. La IA operará **estrictamente** bajo los sesgos lógicos y barreras técnicas de ese rol.
