# USAGE_RULES

## Reglas de uso
- La IA trabaja por bloques cerrados.
- No abrir varios frentes a la vez.
- No pedir refactors masivos sin baseline green.
- No improvisar nuevas features fuera del roadmap.
- Siempre documentar resultado de bloque.
- Siempre usar prompts restrictivos.
- Siempre exigir salida breve.
